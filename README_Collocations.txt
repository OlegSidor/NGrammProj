README – Інструкція до форми пошуку колокацій (CollocationsForm)
1. Що потрібно для запуску?
   - Попередньо повинні бути обчислені n-грамами (буквені, символьні або словесні).
   - Форма відкривається з головного вікна (MainForm) після обробки тексту.

2. Як користуватись:
   1) Введіть n-граму у відповідне текстове поле. Наприклад: "the", "люб", "quick brown".
   2) Виберіть режим пошуку з випадаючого списку:
      - Буквена n-грама в n'-грамах
      - Буквена n-грама в словах
      - Буквена n-грама в реченнях
      - Символьна n-грама в n'-грамах
      - Символьна n-грама в словах
      - Символьна n-грама в реченнях
      - Словесна n-грама в словесних n'-грамах
      - Словесна n-грама в реченнях
   3) Якщо режим вимагає параметр n′ — вкажіть його у полі "n′".
   4) Натисніть кнопку "Пошук", щоб розпочати аналіз.

3. Результати пошуку:
   - Відображаються у таблиці нижче.
   - Колонки:
     - #: Порядковий номер
     - Item: Знайдена структура (слово, речення або n′-грама)
     - Frequency: Частота появи
   - Натискання правою кнопкою миші на елемент — копіює його в буфер обміну.
   - Натискання по заголовку колонки сортує таблицю.

4. Збереження результатів:
   - Натисніть кнопку "Зберегти результати", щоб експортувати таблицю у файл .txt.

5. Обмеження та валідація:
   - n-грама не може бути порожньою
   - У режимах без пробілів (буквені та символьні) заборонено вводити n-граму з пробілами, якщо не увімкнено "враховувати пробіли"
   - Вказана довжина n-грам не повинна перевищувати значення, задані при обчисленні
   - Для словесних n-грам перевіряється правильність слів (без символів)
